## Convenções

- **Voz:** direta, na segunda pessoa ("você"), frases curtas.
- **Nomes de tela e botão** exatamente como aparecem na plataforma, em **negrito**.
- **Caminho:** `Menu → Item → Tela`.
- **Marcador `[A VALIDAR]`:** comportamento descrito a partir do código ou da
  spec e ainda não conferido em uso real.
- **Caixa "O que a plataforma não faz":** obrigatória em todo tópico.
- **Dados de exemplo:** sempre fictícios (Marina Souza, Atlas Logística).

**antes de publicar**. Ver [CONFERENCIA.md](CONFERENCIA.md) e
