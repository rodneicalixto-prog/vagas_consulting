# Conferência antes de publicar uma entrega

Marque cada item. Entrega que muda tela, regra ou limite sem passar por aqui
não está pronta.

- [ ] Os capítulos afetados foram atualizados (listar abaixo)
- [ ] Nomes de tela e botão estão como aparecem na plataforma
- [ ] Caminhos do menu (`Menu → Item → Tela`) existem para o papel citado
- [ ] A matriz de permissões continua correta
- [ ] "O que a plataforma não faz" foi revisto
- [ ] Limites conhecidos das specs estão refletidos
- [ ] Nenhum dado real em exemplo ou captura
- [ ] `[A VALIDAR]` só permanece onde ainda não houve teste
- [ ] Versão do manual e `CHANGELOG.md` atualizados
- [ ] O índice do assistente foi regenerado: `npm run ajuda:indice` (o teste falha se estiver velho)
